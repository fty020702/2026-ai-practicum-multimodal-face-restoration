## 3. 两个真实的坑（不要重复踩）

**坑 1：`pip install -U "diffusers>=0.37"` 装到了 0.42.1，`import diffusers` 直接崩。**

```
AttributeError: module 'torch' has no attribute 'accelerator'
  diffusers/utils/torch_utils.py:245  ->  torch.accelerator.is_available()
```

`torch.accelerator` 是较新 torch 才有的 API，torch 2.5.1 没有。**在不动 torch 的前提下必须把 diffusers 固定在 0.37.1**（第一个带 `Flux2KleinPipeline` 的版本），不能追最新。

**坑 2：`-U "transformers>=4.51"` 装到了 5.22.1，破坏了 `sentence-transformers 2.2.2`。**

先是与 `sentence-transformers` 的版本约束冲突（`requires transformers<5`）；把 transformers 降回 `<5` 后，`sentence-transformers 2.2.2` 仍然 import 失败：

```
ImportError: cannot import name 'cached_download' from 'huggingface_hub'
```

因为 `huggingface_hub` 0.36 移除了 `cached_download`。解法是把 `sentence-transformers` 升到 4.x（仍要求 transformers<5），而不是把 hub 降回去（diffusers 0.37 需要较新的 hub）。

附带：`huggingface_hub 2.4.0` 曾带进 `httpx2` / `httpcore2`，降级后残留造成 h11 版本冲突。卸载这两个残留、把 h11 降回 0.14.0 后 `pip check` 干净。

## 6. 现在还差什么

包已就绪，代码分发层（`src/system.py`）也已接通并通过 toy 回归。真实 4B 路径仍缺两样，但**下载路线已按实测事实修正**：

1. **BF16 完整 pipeline 权重** → `scripts/download_models.py`（默认 `direct` 引擎，下载 `black-forest-labs/FLUX.2-klein-base-4B` 的 21 个文件 / **15.98 GB**，排除重复的 ComfyUI 单文件；G 盘 ~57–59 GB 空闲够放）。
   - `[FACT]` 原定的 FP8 仓库 `black-forest-labs/FLUX.2-klein-base-4b-fp8` **不是可加载 pipeline**：只有 4.09 GB 单文件，无 `model_index.json` / `text_encoder` / `vae` / `tokenizer`，且为 BFL/ComfyUI 原生 scaled-FP8 键；`Flux2KleinPipeline` 无 `from_single_file` / FP8 支持。详见 `docs/方案设计.md` §2.1。
2. **可用显存** → 2026-11-07 多次实测 4070 Ti 空闲仅 **7.1–7.5 GB**，官方 ~13 GB 需求不满足。因此 `load()` 默认整个 pipeline 留在 CPU；GPU 训练需先腾出 ≥ 9 GB 空闲显存，或先用 `--device cpu` 跑契约验证。

下一步固定顺序：`download_models.py`（下载中）→ `inspect_backbone.py` → `precompute_prompts.py` → `verify_real_backend.py` → `train.py --override configs/flux2_klein.yaml --device cpu` → 真实消融。

> 下载引擎注 `[RESULT]`：默认 `direct`（顺序 + Range 断点续传 + `os.replace()`），因为 `snapshot_download` 会为每个文件创建并**删除** `.lock` / `tmp_*`，触发沙箱 `SAFE_DELETE_BULK_CONFIRM_REQUIRED` 而卡在 `1/21`（0.26 MB/s）；改用 `direct` 后恢复到 **5.84 MB/s**。进度见 `scripts/watch_download.py --once` 或 `outputs/logs/download_progress.json`。

`src/system.py::preflight_flux2()` 会在权重 / 显存 / prompt 缓存任一缺失时硬失败，避免半加载状态下静默出错。
