### A — 智能软件方向（第 4 页，本项目应走此路线）
- 示例：低空安防、短剧生成……
- **要求**：
  - **至少两个模型有效协同**
  - **解决一个真实场景问题（不是标准数据集简单串联）**
  - **Demo 达到基本可用（可展示鲁棒性 / 边界情况）**
  - **报告含系统架构图、性能分析**
- 参考研究生实践竞赛要求；鼓励参加 AI 应用竞赛（需提交参赛报告与作品展示）：`https://www.cicas.cn/Home`
- 竞赛导向：针对真实场景 → 设计解决方案 → 开发高质量 Demo → 达到竞赛水平

### B — 具身智能方向（第 5 页，非本项目路线）
导航 VLN / 动作 VLA / 问答 EQA；要求提交 ≥2 分钟硬件视频、系统框图、部署流程、实时性能（FPS、延迟、功耗）、现场或录制演示成功。

### 教学成果示例（第 7 页）
- 应用开发（2–3 人）：可交互的软硬件原型系统 + 商业计划书摘要
- 具身智能（3–6 人）：高逼真仿真 / 实机系统 + 技术宣传片

## 5. 边界

- 课程 PDF 第 2 页为课程群二维码，无教学信息；本文件不含二维码内容。
- 「达成情况」是依据仓库文件与日志的推断，不是老师给出的评分。
- 项目名含「人脸」，但目前只是**老照片人像载体**，没有专门的人脸身份保持模块；真实出图是原生 FLUX.2 能力、非自训旁路，写报告时需注明。
- 一图多目标最新 verdict 为 `NOT-YET-SUPPORTED`（`penalty/gap = 7.28%` < 10%），**不要**用 IP2P A 类的 36.73% 代替。
- 本轮新增的 Demo 与性能分析用的是**原生 FLUX.2 零训练能力**；它满足「Demo 可用 / 指标齐备」的课程要求，但**不构成**项目自训文本旁路有效的证据。
