> **项目**：2026 人工智能实训 —— 多模态参考人脸图像恢复
> **仓库**：GitHub 私人仓库（`private: true`）
> **建仓日期**：2026-11-13

---

## 1. 这个仓库放什么、不放什么

一句话：**只放能重建实验的东西，不放能重新下载/重新生成的东西。**

| 目录 | 是否入库 | 本机体积 | 说明 |
|---|---|---|---|
| `src/` | ✅ | 464 KB | 核心代码：冻结主干、文本条件模块、后端适配、数据工厂、训练/推理 |
| `scripts/` | ✅ | 912 KB | 契约检查、权重下载、数据构建、训练/诊断/可视化/监控脚本 |
| `configs/` | ✅ | 64 KB | 全部实验配置（toy / FLUX.2 / 老照片 / 一图多目标 / IP2P） |
| `docs/` | ✅ | 144 KB | 方案设计、论文对标、事实核实、实验结论 |
| `app/` | ✅ | 12 KB | 演示入口（Gradio 未安装，[UNVERIFIED]） |
| `results/` | ✅ | ~4.5 MB | **精选**成果快照：对比图 + 关键 JSON 报告 |
| `README.md` / `requirements.txt` / `.gitignore` | ✅ | — | 入口与环境约束 |
| `models/` | ❌ | **17 GB** | `FLUX.2-klein-4B-Base` BF16 完整 pipeline |
| `data/` | ❌ | **2.7 GB** | DIV2K / IP2P 500MB 分片 / 自建老照片多目标集 / 离线文本缓存 |
| `outputs/` | ❌ | **1.6 GB** | checkpoints、全量日志、全部原始出图（5226 张图片） |

`results/` 只是 `outputs/samples/` 与 `outputs/logs/` 里**最有代表性的副本**，用于让仓库自包含；完整产物仍留在本机。

`scripts/` 按职责分为四组，命名即用途：

- **契约与验证**：`check_flux2_contract.py`、`check_flux2_train_contract.py`、`verify_real_forward.py`、`test_latent_roundtrip.py`、`inspect_backbone.py`

- **可视化与监控**：`show_*_example.py`、`show_*_summary.py`、`show_ambiguity_ab.py`、`watch_*.py`
- **本次真实出图**：`run_flux2_old_photo_demo.py`、`watch_flux2_demo.py`

## 3. 复现路径

### 3.1 环境（按用户决定：不新建 conda env）

固定解释器 `D:/Anaconda/envs/ChatAI/python.exe`，在 **`ChatAI` 环境内原地升级**，版本组合见 `requirements.txt`。
关键约束：`torch 2.5.1+cu121` 不动；`diffusers 0.37.1`、`transformers 4.57.6 (<5)`、`accelerate 1.0.1`。
**不要追最新版**：`diffusers ≥ 0.42` 需要 `torch.accelerator`（2.5.1 没有）；`transformers ≥ 5` 会破坏 `sentence-transformers`。

### 3.2 秒级自检（不需要权重）

```bash
P=D:/Anaconda/envs/ChatAI/python.exe
$P scripts/check_flux2_contract.py
$P scripts/check_flux2_train_contract.py
$P src/smoke_test.py                       # T1–T6 全 PASS
```

### 3.3 真实权重（本机 17 GB，不入库）

```bash
$P scripts/download_models.py              # BF16 完整 pipeline, 21 文件 / 15.98 GB
```

> `[FACT]` FP8 仓库 `...-base-4b-fp8` 是 ComfyUI 单文件，**不是**可加载的 diffusers pipeline，
> 没有 `model_index.json` / `text_encoder` / `vae` / `tokenizer`。主线只能是 BF16 完整 pipeline。

### 3.4 数据（本机 2.7 GB，不入库）

```bash
$P scripts/fetch_ip2p_shard.py --shard 0                       # 官方 499,831,414 B / 1195 行
$P scripts/build_old_photo_data.py                             # 论文式老化退化
$P scripts/build_old_photo_multitarget.py --groups 800          # 800 组 × 4 目标, 463 MB
$P scripts/build_ip2p_multitarget.py --groups 200              # 官方分片 A 类视图
```

### 3.5 关键实验

```bash
# 严格 A/B：唯一变量 collapse_targets
$P src/train.py --override configs/old_photo_multitarget.yaml --device cuda --steps 1200
$P src/train.py --override configs/old_photo_multitarget_control.yaml --device cuda --steps 1200
$P scripts/diagnose_ambiguity.py --override configs/old_photo_multitarget.yaml \
    --checkpoint outputs/checkpoints/old_photo_multitarget_control/cond_step001200.pt \
    --checkpoint outputs/checkpoints/old_photo_multitarget/cond_step001200.pt \
    --groups 32 --device cpu --out ambiguity_old_photo_ab_g32.json

# 真实 4B 出图（零训练，原生 Qwen3 + 官方 image= 参考图）
$P scripts/run_flux2_old_photo_demo.py --prompt-set restore --tag old_photo --steps 20 --size 512 --limit 4
$P scripts/run_flux2_old_photo_demo.py --prompt-set edit    --tag old_photo_edit --steps 20 --size 512 --limit 4
```

> 代码里的 `D:/Anaconda/...` 与 `G:/研究生生涯相关/...` 是**本机绝对路径**，
> 换机器时需改 `src/utils.py::ROOT` 与配置里的路径；`ROOT` 由 `src/` 的相对位置推导，
> 配置与数据路径都相对它解析。

## 5. 范围与诚实边界

- 项目名称含「人脸」，**当前实现以老照片人像为主要载体**（含人物肖像的修复与指令编辑），
  **尚未**接入专门的人脸身份保持 / 人脸先验 / 人脸关键点模块；不要把它读成已完成的人脸专用模型。
- `results/figures/flux2_*` 是**原生 FLUX.2 模型能力**的定性演示（零训练、20 步、单 seed、目视），
  不是本项目训练出的文本旁路，也没有 PSNR / SSIM / LPIPS / 用户研究。
- 一图多目标 toy 实验最新 verdict 为 `NOT-YET-SUPPORTED`（`penalty/gap = 7.28%` < 10% 阈值），
  **不要**引用旧的 36.73%（那是 IP2P A 类视图）代替它。
- 文档里的 `[FACT]` / `[RESULT]` / `[INFERENCE]` / `[HYPOTHESIS]` 是事实分级，不要混用。

## 6. 隐私与安全

- 仓库为 **private**；没有提交任何 token、密码、密钥或凭据文件。
- 17 GB 模型权重、2.7 GB 数据不入库，避免触犯模型/数据集许可与大文件限制。
- `.gitignore` 额外排除了 `*.pt` / `*.safetensors` / `*.parquet` / `.incomplete` / `__pycache__` / `*.log`，
  防止误提交；提交前请用 `git status --short` 与 `git diff --cached --stat` 复核。
