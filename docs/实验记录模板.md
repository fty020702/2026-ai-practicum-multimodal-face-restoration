# 实验记录模板

> 用途：每次跑实验（toy 回归 / 真实基座训练 / 消融）复制一份，填完存到
> `outputs/logs/experiments/YYYYMMDD_<name>.md`。
> 铁律：**每个数字都要标事实级别**，不要把 `[RESULT]` 外推成 `[FACT]` 或真实模型结论。
> 级别：`[FACT]` 源码/文档可确认 · `[RESULT]` 本次真实跑出 · `[INFERENCE]` 推断 ·
> `[HYPOTHESIS]` 未验证猜想 · `[UNVERIFIED]` 待真实环境验证。

## 7. 已知混淆 / 风险 `[FACT]`

- 数据集中退化类型与 prompt **严格一一对应**，文本与图像信息冗余。真实基座上做
  "文本是否有用"的结论前，必须随机化内容级提示，或构造同一图像配不同任务提示的对照，
  否则无法排除"模型只看了参考图、完全忽略文本"。
- 文本扰动测试必须**复用同一初始噪声**，否则差异可能来自采样噪声而非文本。
- `projector_only` 曾因双重零初始化导致梯度死锁（`d_text = 0`）；若再次出现查
  `docs/方案设计.md` §4。
- `LPIPS` 首次构造会下载权重，离线跑默认 `use_lpips=False`。
